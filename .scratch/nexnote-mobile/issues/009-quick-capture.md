# MOB-009 快速捕获与捕获目录

Ticket: MOB-009 · Milestone: M4 · Branch: dev/MOB-009 · Depends: MOB-004
Status: implemented —— 捕获目录可配、首行标题、默认元数据头、同名不覆盖、冲突禁写拒绝；7 项单测 + 旅程验证；截图 08

## 目标

在手机端任意位置显式新建页面并落入捕获目录，作为碎片信息的低摩擦入口。

## 行为

1. 全局捕获入口（建议从导航层常驻）打开输入界面，输入内容后创建页面。
2. 落点目录可配置（默认 `Inbox/`）；目录不存在时创建。
3. 默认元数据头：`created`（当前时间）、`type`（捕获类型值）；`title` 取正文首行，超长时截断并保证可作为文件名。
4. 文件名冲突时追加序号，不覆盖既有页面。
5. 创建后立即触发自动提交，并在界面给出「已捕获」确认与跳转到该页面的入口。

## 边界

- 不引入新的领域对象：捕获即页面，可被双链、可被搜索、可被桌面端编辑。
- 不做剪贴板监听、分享面板扩展、图片/附件捕获（后续票）。

## 验收

- 真机上完成捕获：页面出现在捕获目录树中、元数据头合规、桌面端 pull 后可见并可双链。
- 修改捕获目录设置后，新捕获落到新目录且旧页面不受影响。
- 同名捕获与超长首行捕获均不产生覆盖或非法文件名。
