# MOB-007 基础编辑：源码模式与块模型

Status: implemented —— 源码模式（frontmatter 只读）+ 简化块编辑（段落/标题/列表/任务/引用/代码/图片）；只读结构原样保留

## 目标

实现手机端的基础编辑能力：Markdown 源码编辑与简化块编辑，共享同一文档模型。

## 行为

1. 文档模型：页面正文以 Markdown 原文为权威，块模型为同一文本的解析视图；保存时只写回被修改的部分，未修改内容逐字节不动。
2. 源码编辑：完整原文编辑（语法可见），元数据头只读展示、不参与编辑。
3. 简化块编辑：可编辑块类型为段落、标题、无序/有序列表、任务列表、引用、代码块、图片；表格、公式、图表块为只读占位。
4. 不支持结构规则：块模式遇不支持结构时原样保留、只能经源码模式编辑，禁止静默改写。
5. 保存链路：编辑保存 → 触发自动提交（MOB-004 的防抖与消息前缀）；冲突禁写态下保存被阻止并给出提示。

## 边界

- 不做元数据头编辑、不做表格/公式/图表编辑、不做移动块/多选/拖拽等桌面块编辑高级能力。
- 不实现 Markdown 序列化往返以外的格式转换。

## 验收

- 字节保真：仅打开不编辑，文件字节不变（哈希对比）；编辑一处段落，其余字节不变（diff 仅一处）。
- 含表格、公式、图表、内嵌 HTML 的页面在块模式打开后保存，桌面端打开零漂移。
- 保存触发的自动提交消息符合 `nexnote:auto:` 约定，且被桌面端识别为自动提交。
