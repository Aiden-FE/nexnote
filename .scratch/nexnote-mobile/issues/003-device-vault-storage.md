# MOB-003 设备知识库与存储层

Ticket: MOB-003 · Milestone: M1/M2 · Branch: dev/MOB-003 · Depends: MOB-002
ADR: docs/adr/0019-mobile-data-and-capability-locality.md
Status: open

## 目标

确定设备知识库的落盘位置、目录约束与安全边界，作为 Git 服务、索引与阅读侧的公共底座。

## 行为

1. 设备知识库根目录固定为 `Library/Application Support/<app>/vaults/<name>`（不使用 Documents、不使用 Caches），并对其标记 `NSURLIsExcludedFromBackup`。
2. 启动时校验排除备份标记是否仍然存在（系统升级/迁移后可能丢失），失效则重新标记并记录日志。
3. 所有路径操作经统一的路径校验层：拒绝越出知识库根目录的路径、拒绝符号链接穿透，与桌面端 `safeVaultPath` 的意图对齐（失败语义为显式错误，不静默降级）。
4. 提供知识库元信息读取：当前分支、远端 URL（脱敏输出）、未推送提交数、最后同步时间。
5. 应用启动时若存在未推送提交，呈现显式提示（设备端是这些提交的唯一副本）。

## 边界

- v1 支持单个设备知识库；多知识库切换不做。
- 不负责 Git 运算本身（MOB-004），本票只提供路径与元信息。

## 验收

- 真机上验证目录位置与备份排除标记（给出读取文件属性/系统的证据）。
- 路径逃逸用例：`..`、绝对路径、符号链接指向库外目录，三者均被拒绝且不产生写入。
- 未推送提交提示在真机上可见（构造本地提交后断网启动）。
- 日志不输出凭证、不输出完整远端 URL。
