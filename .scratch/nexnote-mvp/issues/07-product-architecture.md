# 07 · 产品架构对齐：模块边界与信息架构

Type: grilling
Status: open

## Question

全模块 MVP 的产品架构定稿（HITL，与用户对齐）：

1. 五大模块（块编辑文档、双链 & 元数据 & 知识关系、AI 融合、Git 底座、检索 Skill 系统）的边界与依赖关系图；插件系统横切各模块的方式。
2. 信息架构：库 → 页面 → 块的导航与组织模型（侧栏、面包屑、搜索入口、图谱入口）。
3. 产品行为：双链 / 别名 / 回链的交互、元数据编辑面、图谱视图的产品角色、置信度在 UI 的呈现位置。
4. AI 产品面：写作辅助的入口（块菜单 / 选区）、独立对话面板、会话保存为文档、上下文注入的选择器。
5. 插件与 Skill 的用户面：安装 / 启用 / 组合的最小产品闭环。

产出：产品架构定稿（后续整案原型的信息架构输入），新领域术语沉淀进 CONTEXT.md。研究票 01–06 的发现物（docs/research/）可作背景，但本票是产品层决策，不阻塞于研究。
