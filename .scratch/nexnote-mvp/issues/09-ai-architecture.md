# 09 · AI 架构对齐：适配层、上下文注入与召回

Type: grilling
Status: open
Blocked by: 05, 08

## Question

基于研究票 05（docs/research/ai-vector.md）与技术架构收敛票 08 的组合，与用户对齐 AI 层架构：

1. AI 供应商适配器设计：OpenAI 协议面、用户配置（base-url / key / 模型 / 参数）、流式链路、扩展点预留。
2. 写作辅助管线：块级 / 选区改写、扩写、润色等操作的请求组装与结果回写（块替换 vs 追加）。
3. 对话面板：会话存储格式、保存为文档的映射、与文档上下文注入选择器的关系。
4. 渐进式召回管道：粗筛 → 双链扩展 → 向量重排三阶段的工程位置（Skill 内）、置信度 → 召回权重挂钩方式、向量索引构建与增量更新时机。

产出：AI 层架构决策（ticket 内 Answer），可酌情落 ADR。
