## Answer

覆盖面与交互（可点击验证）：

- **AI 原生驾驶舱主界面**：右侧 cockpit 占 ~41% 宽度为主组织面（上下文注入 chips → 对话线 → 渐进召回面板 → 引用答案），编辑器退居中栏；上下文注入支持当前页/选区/关联双链 chips 增删与搜索式选择器。
- **渐进召回过程可视化（hero）**：发送问题后 S1 粗筛（FTS5+标签+frontmatter）→ S2 双链 1–2 跳扩展（节点扩散动画，12→34 候选）→ S3 向量重排逐阶段点亮，含命中数与耗时。
- **置信度参与召回权重**：重排 bar 图同时显示 `sim` 与 `final = sim · confidence^0.7`，展示置信度抬升/压低排序（is-lift ↑ 标注）；召回算式可 toggle 显隐；frontmatter 属性面板呈现置信度分数 + 构成因子。
- **文档与块编辑（基线）**：块 hover gutter（拖拽/+）、选区浮动 AI 工具栏（6 动作，改写触发 diff 预览接受/拒绝）、`/` 斜杠命令菜单、wikilink 补全样式（含未创建占位）、`^block-id` 铬点、frontmatter 表格↔YAML 双模式、回链/标签侧栏面板。
- **Git 状态**：状态栏（分支/变更数/最后提交 + Pull/Push 确认弹窗含凭证预检说明）、版本时间线抽屉（自动提交折叠分组、手动提交标注、hunk 级回滚入口）。
- **会话即页面**：驾驶舱「保存为页面」一键落为 `type: chat` 页面（新 tab + 树中 chat 徽标，可双链可版本化）。
- **检索 Skill 抽屉**：S1/S2/S3 Skill 列表（启用/排序/参数），顺序即召回阶段执行顺序。
- 原型内注明绑定技术栈与取舍一句话（顶部 banner + About 弹窗）：三案同栈，差异在产品形态；**C 的代价 = 编辑器让出近半宽度给 AI 驾驶舱，换取「AI 作为原生层」的可信验证，仅在 AI 确为一级价值时成立**。
