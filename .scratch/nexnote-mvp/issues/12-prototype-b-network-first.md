### 设计定向

- **视觉语言**：「夜间星图 / knowledge atlas」——深靛石墨底 × 极光青双链 × 琥珀标签 × 宋式衬线页标题（Songti SC）；发丝线 UI，图谱物理模拟常驻呼吸感。
- **产品形态主张**：知识网络是一等公民。每个页面右栏常驻「局部图谱（1–2 跳）+ 相关页面 + 反向链接 + 文件信息」；首页即全局图谱；节点可拖拽、双击打开。编辑器服务于网络，而非相反。
- **密度 / 动效**：默认舒适密度，Tweaks 面板提供紧凑模式、图谱辉光、界面动效三档开关；遵循 `prefers-reduced-motion`。

### 绑定技术栈（三案同绑，08 号票默认栈）

Electron + React 18 + TypeScript · TailwindCSS + shadcn/ui · TipTap 3（@tiptap/markdown / UniqueID / DragHandle / Suggestion）· MD + YAML frontmatter（Obsidian 公开方言）· SQLite 单库（FTS5 + Link Index + sqlite-vec）· simple-git 调默认捆绑 Git（dugite-native）+ 系统凭证/SSH 环境集成。

**取舍一句话**：同赛道先例最全、块编辑器生态最稳，代价是接受 Electron 的体积与内存底线（~187 MB 基准）；三案差异不在栈而在产品形态——B 案主张图谱与回链是一等公民，编辑器为知识网络服务。

### 验证（浏览器冒烟）

- 控制台无报错
- 核心交互全通：标签页切换、双链跳转、图谱节点双击、AI 三阶段召回 + 来源展开、时间线折叠 + hunk 级回滚、命令面板、设置四页签、上下文选择器、标签视图
- 布局无 zero-size、无文本溢出
- 遵守 `prefers-reduced-motion`、无 `scrollIntoView`
