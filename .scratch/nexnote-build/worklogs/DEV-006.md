# DEV-006 · 图谱视图（全局 + 局部）工作记录

## 方案

- shared 增加 `GraphPage / GraphLink / GraphSnapshot` 与 `index:graph` IPC 契约。
- `LinkIndexService.graph()` 用三组单查询读取页面 metadata、入度/出度、去重已解析链接；红链与孤立资产不入边。
- renderer 使用 React Flow：`filterGraph` 支持标签/文件夹子树与孤立页开关；`localGraph` 做 1/2 跳收缩；`layoutGraph` 是确定性、迭代有界的弹簧布局；`graphElements` 负责入度尺寸和选中邻接高亮。
- 全局图谱作为独立 graph tab，命令 ID 为 `view.graph`；局部图谱注册为侧栏 `graph` 面板，随 active page 更新。
- `index:statusChanged` 到 ready 时，已 ready 的 graph 状态转为 stale 并自动重拉，避免增量索引后显示旧图。

## 实现与修复

- `@xyflow/react` 放入 `@nexnote/renderer` dependencies，确保 pnpm peer 解析到应用唯一 React 19.2.8；误放 root 会引入第二份 React 17 并触发 `Invalid hook call`。
- `better-sqlite3` 声明到 root dependencies，使 electron-vite 的依赖 external 扫描与 Electron runtime 从根 `node_modules` 解析一致；避免 Rollup 打包 native `.node`。
- smoke 输出目录支持 `NEXNOTE_SMOKE_DIR`，DEV-006 证据不再覆盖 DEV-007。
- `applyStatusEvent` 收敛 stale 判断；`index-store` 新增 graph load/stale 测试。
