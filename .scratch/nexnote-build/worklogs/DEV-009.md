### 关键契约

- **密钥安全**：渲染层 `AiProfileView` 无 `key` 字段，仅 `hasApiKey: boolean` + `keyStorage: 'system-credential'`。写 Profile 时密钥一次性经 IPC 流入主进程 → OS keyring 保存 → JSON 只保存 opaque account ref。keyring 不可用时保存带 key 的 Profile 明确失败，绝不写 JSON 明文；遗留 `plain:` blob 立即清除，legacy `enc:v1:` 只在解密和 keyring 写入都成功后才替换。candidate token 绑定 normalized origin，保存时一次性消费。authenticated provider fetch 一律 `redirect: 'error'`，embedding 空/非有限向量 fail-closed。任何 `ai:*` 响应或推送事件 payload 经契约测试扫描不含明文；导出也永不含密钥。
- **统一流事件协议**：`ChatStreamEvent = start | delta | reasoningDelta | done | error`，由 Adapter 层在 HTTP 200 后发出 `start`，SSE `[DONE]` → `done`，状态码/网络异常 → `error(code)`。Service 只做 streamId 包装并经 `ai:streamEvent` 推送；订阅方按 streamId 过滤。
- **Capabilities 实测**：连接测试分别执行非流式 chat、真实 SSE streaming、带 `tools` schema 的最小 chat、embeddings 请求；四项互相独立并保守上报，不能由普通 chat 或模型列表推断全部能力。
- **Profile 解析优先级**：显式 `profileId` > `feature` 指定（writing/chat/embedding）> 全局默认 Profile。Model 同优先级。编辑候选测试允许同时传 `profileId + candidate`：主进程只复用已存密钥，网络目标按候选 kind/baseUrl/defaultModel 实测。
- **embedding generation**：指纹 `profileId:model:dimensions:cosine` 变化 → `embeddingGeneration++`（DEV-011 消费以标记索引重建）。`recordEmbeddingDimensions()` 返回是否变更；首次维度回写后广播 `ai:configChanged`，同维度重复 embed 不重复广播。
- **Embedding 接口**：公共 `AiService.embed(texts): Promise<number[][]>` 与规格对齐；内部/IPC 通过 `embedWithMetadata()` 保留 dimensions/model/profileId。`LocalEmbeddingAdapter` 提供 hash-384 本地降级实现。
- **降级路径**：未配置（`needsOnboarding=true`）→ 所有 AI 入口经 `aiEntryOrWizard(action)` 守卫，转向导；请求失败 → 调试面板错误 + 重试按钮；embedding 不可用 → `embed()` 抛 `BAD_EMBEDDING`，由 DEV-011 召回管道降级。

## 已知限制

- **本地小模型 Embedding**：已提供 `LocalEmbeddingAdapter` 明确 seam，当前按票据允许仅返回/抛 `NOT_IMPLEMENTED`；实际模型加载与召回降级由 DEV-011 接入。
- **Embedding 分批 token 估算**：用字符数（保守 24000 chars ≈ 6k tokens）代替真实 tokenizer；接受 1 批 N 条 / 总字符 ≤ 上限 + 单条超限时独占一批的语义。真实 token 数随模型变化，足够 MVP。
- **设置页承载壳**：`SettingsPage` 是 DEV-016 完整设置系统前的最小结构（左侧分区导航 + 右侧分区内容，注册表驱动）。已跨模块最小改动（tab kind + 命令），不涉及设置系统的搜索/导入等高级特性。
- **safeStorage 不可用环境**（部分 Linux 无 keyring）：无密钥的本地服务 Profile 仍可创建；带 API Key 的 Profile 保存会明确失败并提示启用系统钥匙串，绝不明文降级。
- **Azure 鉴权细节**：当前实现使用 `api-key` 头（Azure 推荐），AAD 令牌鉴权未实现（不在 MVP 范围）。
