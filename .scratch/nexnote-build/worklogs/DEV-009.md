# DEV-009 · AI Provider Adapter 与配置系统 — 设计

## 模块归属

- `packages/shared`：AI 类型（Profile/能力/流事件/配置状态）+ `ai:*` IPC 通道契约 + 推送事件（`ai:streamEvent` / `ai:configChanged`）
- `packages/main`：
  - `src/ai/provider/sse.ts` — 增量 SSE 解析器（跨 chunk 安全）
  - `src/ai/provider/openai.ts` — OpenAI 协议适配器（openai-compatible / azure-openai 变体，fetch 注入）
  - `src/ai/secret-store.ts` — 密钥保险库（Electron safeStorage 可注入；不可用时明文回退并标记）
  - `src/ai/ai-store.ts` — Profile/分功能指定/导入导出/embedding generation（JSON 持久化，密钥仅存加密 blob）
  - `src/ai/ai-service.ts` — 组装层：profile→adapter、chat/stream（AbortController + 事件推送）、embed 分批、testConnection/capabilities
  - `src/ipc/ai-handlers.ts` — `ai:*` handler 注册
- `packages/renderer`：
  - `pages/SettingsPage.tsx` — 设置页最小承载壳（消费 settingsSectionRegistry；DEV-016 完整化）
  - `features/ai/*` — 设置分区（Profile 管理/分功能指定/导入导出/调试面板）、首启动向导、dock 空态改造
  - `features/dock/index.tsx` — AI 占位 render 指向本票空态组件
- smoke：主进程内嵌 mock OpenAI 协议服务器（127.0.0.1 随机端口），渲染层冒烟新增 AI 场景

## 关键契约

- 密钥流向：渲染层仅一次性收集用户输入 → IPC 发往主进程 → safeStorage 加密 → JSON 存 blob；任何 `ai:*` 响应/事件 payload 不含明文 key（契约测试扫描）。
- 流式：`ai:chat:stream:start` 返回 streamId，后续经 `ai:streamEvent` 推送统一内部事件（start/delta/reasoningDelta/done/error），`ai:chat:stream:cancel` 中止。
- profile 解析优先级：显式 profileId > feature 指定 > 全局默认。
- embedding generation：指纹 `profileId:model:dimensions:metric` 变化 → generation+1（DEV-011 消费，触发索引重建标记）。
