### 关键契约

- **密钥安全**：渲染层 `AiProfileView` 无 `key` 字段，仅 `hasApiKey: boolean` + `keyStorage: 'safestorage'|'plain'`。写 Profile 时密钥一次性经 IPC 流入主进程 → safeStorage 加密 → 落盘只存 `enc:v1:base64(blob)`。任何 `ai:*` 响应或推送事件 payload 经契约测试 `JSON.stringify(...).not.toContain(SECRET)` 扫描。导出 Profile 捆绑按白名单仅含 name/kind/baseUrl/model/params，永不含密钥。
- **统一流事件协议**：`ChatStreamEvent = start | delta | reasoningDelta | done | error`，由 Adapter 层在 HTTP 200 后发出 `start`，SSE `[DONE]` → `done`，状态码/网络异常 → `error(code)`。Service 只做 streamId 包装并经 `ai:streamEvent` 推送；订阅方按 streamId 过滤。
- **Profile 解析优先级**：显式 `profileId` > `feature` 指定（writing/chat/embedding）> 全局默认 Profile。Model 同优先级。
- **embedding generation**：指纹 `profileId:model:dimensions:cosine` 变化 → `embeddingGeneration++`（DEV-011 消费以标记索引重建）。维度首次 embed 成功后回写（`recordEmbeddingDimensions`）。
- **降级路径**：未配置（`needsOnboarding=true`）→ 所有 AI 入口经 `aiEntryOrWizard(action)` 守卫，转向导；请求失败 → 调试面板错误 + 重试按钮；embedding 不可用 → `embed()` 抛 `BAD_EMBEDDING`，由 DEV-011 召回管道降级（按本票约定不实现召回层）。

## 已知限制

- **本地小模型 Embedding**：按票据约定留接口（`ProviderAdapter` 已有 `embeddings`；后续以独立 `LocalModelEmbeddingAdapter` 实现接入），MVP 不实现；降级由 DEV-011 召回层处理。
- **tools/function-calling**：协议级默认 `true`（OpenAI 协议支持）；真实探测留待 DEV-010（写作辅助引入工具调用时按需细化）。
- **Embedding 分批 token 估算**：用字符数（保守 24000 chars ≈ 6k tokens）代替真实 tokenizer；接受 1 批 N 条 / 总字符 ≤ 上限 + 单条超限时独占一批的语义。真实 token 数随模型变化，足够 MVP。
- **设置页承载壳**：`SettingsPage` 是 DEV-016 完整设置系统前的最小结构（左侧分区导航 + 右侧分区内容，注册表驱动）。已跨模块最小改动（tab kind + 命令），不涉及设置系统的搜索/导入等高级特性。
- **safeStorage 不可用环境**（部分 Linux 无 keyring）：`keyStorage='plain'` 回退并在 Profile 卡片显式标记「⚠ 明文回退」。生产环境 macOS/Windows 走系统钥匙串。
- **Azure 鉴权细节**：当前实现使用 `api-key` 头（Azure 推荐），AAD 令牌鉴权未实现（不在 MVP 范围）。
