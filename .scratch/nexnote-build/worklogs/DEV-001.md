## 实施摘要

1. 建立 pnpm workspace：`main`、`renderer`、`shared`、框架无关的 `kernel`；启用 TypeScript strict、ESLint 和 Prettier。
2. 建立安全的 Electron 主进程：单实例、窗口生命周期、受限导航/权限、`contextIsolation`、sandboxed preload、关闭 renderer Node integration。
3. 建立共享的、命名空间化并类型化的 IPC 合约；主进程实现 vault 与文件系统 handler，其他业务命名空间提供明确占位 ping。
4. 实现 vault 创建/打开/关闭、`.nexnote/config.json`、布局和最近 vault 存储；文件操作只接受 vault 相对路径并校验路径逃逸及符号链接逃逸。
5. 实现 React/Tailwind/shadcn 风格应用壳、注册表插槽、三面板/状态栏、可收起且可调整尺寸的 sidebar、Tab、分屏、主题、⌘K 和向导。
6. 新增 GUI 冒烟模式，产出真实 Electron 截图及结果 JSON。
