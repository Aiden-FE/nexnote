# DEV-005 工作日志 · 元数据：frontmatter 双模式与属性面板

## 方案思路

- **结构化模型放 kernel**：`packages/kernel/src/frontmatter/model.ts` 提供零依赖的
  frontmatter YAML 解析/序列化（string / number / boolean / date/datetime / list / null），
  类型保真 round-trip。未引入 js-yaml：MVP 字段域有限，接口留作后续替换点。
- **双模式 UI**：`FrontmatterPanel`（编辑器顶部）表格模式 ↔ YAML 源码模式；
  YAML 编辑器用覆盖层轻量高亮 key/value/注释/atom，并在 300ms 防抖后写回。
- **数据安全**：打开文档时 `inspectFrontmatter` 先检验 YAML；不可解析则强制锁定源码模式，
  表格按钮禁用、原始 YAML 保留，直到用户修复为可解析格式。不可解析内容永不触发结构化写回。
- **局部事务更新**：表格/YAML 编辑只通过 ProseMirror transaction 替换文档首部
  `frontmatter` 节点，不再 `setMarkdown` 重建整篇正文，因此保留正文光标映射和撤销历史。
- **属性面板**：注册为右 Dock「属性」页签，展示全部标准和自定义字段、置信度占位
  （DEV-008 接入）、链接计数占位（DEV-004 接入）、中西文混合字数/块数、时间和路径。
- **标签联动**：递归扫描 vault 全部子目录内 Markdown frontmatter tags 作为自动补全集；
  跳过 `.git/.nexnote/.trash/node_modules`，接口可由 DEV-004 索引替换。
- **系统文件管理器**：新增类型安全 IPC `vault:reveal`，主进程沙箱解析路径后调用
  Electron `shell.showItemInFolder`，不再把“在 Finder 中显示”实现成复制路径。

## 代码实现

- kernel：`src/frontmatter/model.ts`（解析/序列化/辅助），`src/index.ts` 导出。
- renderer：
  - `features/frontmatter/FrontmatterPanel.tsx` — 双模式容器、源码锁定、语法高亮、300ms 防抖；
  - `features/frontmatter/FieldEditor.tsx` — 类型化编辑器、datetime 时间保留、标签自动补全、字段增删改名；
  - `features/frontmatter/PropertiesPanel.tsx` — 全部字段、统计、置信度/链接 seam、真实 reveal；
  - `features/frontmatter/frontmatter-utils.ts` — 安全 inspect、混合字数、YAML tokenizer、递归标签聚合；
  - `features/frontmatter/document-properties-store.ts` / `registry.tsx` — Dock 数据与注册；
  - `editor/EditorView.tsx` — 安全加载锁定、frontmatter 节点局部事务、递归标签扫描；
  - `features/bootstrap.ts` — 注册装配。
- IPC：`shared/ipc/channels/vault.ts` 增加 `vault:reveal`，主进程 services/handler 接入
  `shell.showItemInFolder`。
