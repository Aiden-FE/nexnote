# DEV-005 工作日志 · 元数据：frontmatter 双模式与属性面板

## 方案思路

- **结构化模型放 kernel**：`packages/kernel/src/frontmatter/model.ts` 提供零依赖的
  frontmatter YAML 解析/序列化（string / number / boolean / date / list / null），
  类型保真 round-trip。未引入 js-yaml：MVP 字段域有限，接口留作后续替换点。
- **双模式 UI**：`FrontmatterPanel`（编辑器顶部）表格模式 ↔ YAML 源码模式；
  源码模式带行数/校验状态提示，解析失败停留源码模式并标红（不丢输入）。
- **属性面板**：注册为右 Dock「属性」页签（`features/frontmatter/registry.tsx`），
  展示基本信息 / 置信度占位（DEV-008 接入）/ 链接计数占位（DEV-004 接入）/
  词数块数 / 创建更新时间 / 路径。
- **数据流**：`EditorView` 持有 fmData/fmSource；表格/YAML 编辑 →
  `applyFrontmatter` 重建文档 Markdown（`---\n…\n---\n\n正文`）→ kernel.setMarkdown
  → 防抖保存落盘；同时同步 `document-properties-store` 供 Dock 面板读取。
- **标签联动**：打开页面时扫描 vault 根 .md 的 frontmatter tags 作为自动补全集；
  tags 修改随 frontmatter 保存，标签面板（DEV-003 树）随文件事件刷新。

## 代码实现

- kernel：`src/frontmatter/model.ts`（解析/序列化/辅助），`src/index.ts` 导出。
- renderer：
  - `features/frontmatter/FrontmatterPanel.tsx` — 双模式容器；
  - `features/frontmatter/FieldEditor.tsx` — 字段行 + 类型化编辑器（文本/数字/开关/日期/列表）+ 标签自动补全 + 新建 + 字段增删改名校验；
  - `features/frontmatter/PropertiesPanel.tsx` — 文档属性面板（含置信度 mock 展示位）；
  - `features/frontmatter/frontmatter-utils.ts` — 读/写/改/删/重命名 + `pageStatistics`；
  - `features/frontmatter/document-properties-store.ts` — 激活文档属性 store；
  - `features/frontmatter/registry.tsx` — Dock 注册；
  - `editor/EditorView.tsx` — 面板挂载 + frontmatter 状态 + 标签扫描 + 属性同步；
  - `features/bootstrap.ts` — 注册装配。

  新增 kernel frontmatter 10 用例 + renderer utils 8 用例）。

## 最终验收结果

- ✅ 属性表格与 YAML 模式切换数据一致（serialize↔parse 对称 + 用例覆盖）
- ✅ 修改 frontmatter 后保存，重新打开不变形（`readFrontmatter/writeFrontmatter` 往返用例）
- ✅ 自定义字段的各种类型编辑正常（string/number/boolean/date/list 编辑器 + null 引导）
- ✅ 标签输入支持自动补全 + 新建（knownTags 聚合 + ListEditor）
- ✅ 文档属性面板展示正确的入链/出链数（占位 0，DEV-004 接口已留）、字数等统计

已知边界：YAML 解析不支持深层嵌套 map 与多行块标量（|/>），命中时源码模式标红并
保留原文；深层结构需求出现时替换为 js-yaml（接口不变）。
