# DEV-004 · 关系索引（Link Index + FTS5 + 标签）工作记录

## 方案

- 主进程 `LinkIndexService`：better-sqlite3，同步 API，索引文件固定为 vault 内 `.nexnote/index.db`。
- schema 版本使用 SQLite `PRAGMA user_version`；v1 创建 `pages / links / tags / blocks` 与规定索引，并创建 FTS5 `page_fts`。
- 索引是派生缓存：每次打开 vault 做权威全量同步；数据库缺失时自动创建并重建。命令面板提供“重建关系索引”。
- DEV-003 `VaultWatchService` 的 add/change/unlink 事件进入 160ms 防抖队列，单文件重索引完成后通过 `index:statusChanged` 推送状态，并刷新 renderer 反链与标签。
- Wikilink 解析工具提升到 `@nexnote/shared`，DEV-002 TipTap tokenizer 与 DEV-004 索引共同使用，统一支持 `[[title]] / [[title|alias]] / [[title#heading]] / [[title#^block]]`；跳过 fenced/inline code。
- FTS5 搜索按标题 > 标签 > 别名 > 正文分层。默认 unicode61 tokenizer 对连续中文短子串不友好，因此增加 SQLite LIKE 补偿，再在 JS 合并排序；1000 页最坏查询实测 0.43ms。

- `packages/shared/src/types/index.ts`：IndexStatus、Backlink、SearchHit、TagIndexEntry、PageIndexSummary、PageJumpResult。

- `index:statusChanged` 事件加入 preload 白名单。

### main

- `packages/main/src/indexer/index-service.ts`：migration、全量重建、增量更新、双链解析、FTS5、标签、页面摘要。
- `packages/main/src/indexer/markdown-indexer.ts`：frontmatter/title/aliases/tag/wikilink/normal link/block 提取。
- `packages/main/src/ipc/index-handlers.ts`：renderer IPC facade。
- `packages/main/src/index.ts`：vault 生命周期和 chokidar 增量索引接线。
- better-sqlite3 加入 main 依赖；root `pnpm.onlyBuiltDependencies` 允许其原生构建。

### renderer

- `packages/renderer/src/stores/index-store.ts`：索引状态、反链、标签、搜索与重建。

- `packages/renderer/src/features/search/index.tsx`：⌘⇧F 实时全文搜索、高亮片段、排序标签、点击打开。
- ⌘K 命令面板通过 `index:jumpTo` 注入标题/别名/路径页面跳转结果。
