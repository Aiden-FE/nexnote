## Scope

实现 AI 写作辅助功能：三个入口（选区浮动工具栏 / 斜杠命令 / 右键菜单）、六个动作（改写/扩写/缩写/润色/查漏补缺/补充论据）、diff 预览式回写。

### 交付内容
1. **选区浮动工具栏**
   - 选中文字后浮现工具栏（TipTap 扩展）
   - 按钮：改写、扩写、缩写、润色、查漏补缺、补充论据（六动作 MVP）
   - 工具栏位置：选区上方居中，自适应位置
   - 可通过键盘快捷键触发

2. **斜杠命令中的 AI 动作**
   - `/ai` 子菜单：列出六个 AI 动作
   - 在空块中触发 = 基于上方上下文生成
   - 在选区中触发 = 作用于选区

3. **右键菜单**
   - 右键选中文本 → AI 子菜单 → 六动作
   - 右键块手柄 → AI 改写（作用于整块）

4. **请求组装管线**
   - 上下文组装：选区/块内容 + 当前文档前后文摘要 + 可选反向链接文档摘要
   - token 预算优先级：选区/块 > 当前文档 > 反向链接文档 > 召回文档（召回上下文在 DEV-011 接入，本票先不用召回）
   - 超限截断 + 用户提示（"上下文过长，已截断"）
   - 每动作对应 system prompt + 用户提示模板

5. **Diff 预览式回写**
   - 替换类动作（改写/润色/缩写）：原地 diff 视图（高亮增删）
   - 追加类动作（扩写/补充论据/查漏补缺）：在下方或光标处插入新块，diff 标注
   - 接受 / 拒绝 按钮
   - 接受后可撤销（纳入编辑器 undo 栈）
   - 流式显示：生成过程中实时展示 diff 进度

6. **对话回答插入**
   - 对话 dock 中的 AI 回答可「插入为块」到当前编辑器
   - 插入位置：光标处或文档末尾
   - 插入后也可撤销

## 验收标准
- 选中文字后浮动工具栏出现，六个动作均可触发
- 触发后流式生成结果，以 diff 形式展示
- 接受后内容正确写入编辑器，可撤销
- 拒绝后原文不变
- 斜杠命令和右键菜单路径均可触发 AI 动作
- 长文档上下文超长时有截断提示
