## Scope

完善编辑器的交互细节：斜杠命令菜单、块拖拽手柄、块菜单、选中悬浮工具栏（文本格式化 + AI）。这些是编辑器体验的核心交互，在 DEV-002 骨架基础上深化。

### 交付内容
1. **斜杠命令菜单**
   - 触发：输入 `/` 时弹出
   - 分组：基础块（标题/段落/列表/任务/引用/代码块/表格/分割线）、媒体（图片/附件）、高级（callout/Mermaid/KaTeX）、AI（AI 动作）
   - 搜索过滤：继续输入实时过滤
   - 键盘导航：上下选择 / Enter 确认 / Esc 取消
   - 支持插件注册的命令和块类型（接 DEV-014）

2. **块拖拽手柄**
   - 悬停块时左侧出现手柄
   - 拖拽 = 重排块
   - 点击手柄 = 打开块菜单
   - 支持多选拖拽（MVP 可能简化为单块）

3. **块菜单**
   - 点击块手柄弹出
   - 操作：复制 / 剪切 / 删除 / 复制块 ID / 转换为（改块类型）/ 上移 / 下移 / 折叠 / 在上方插入 / 在下方插入
   - AI 子菜单（接 DEV-010）
   - 支持插件注册菜单项（接 DEV-014）

4. **文本选中悬浮工具栏**
   - 选中文本时浮现
   - 格式化按钮：粗体、斜体、删除线、行内代码、链接
   - AI 按钮（接 DEV-010 的六动作）
   - 高亮 / 颜色（MVP 可能简化）

5. **链接补全**
   - 输入 `[[` 弹出 wikilink 补全菜单
   - 补全项：页面标题 + 别名，带路径预览
   - 支持 `[[title|alias]]` 别名语法
   - 支持 `[[title#heading]]` 锚点语法
   - 未创建页面（红链）标灰显示，回车可创建

6. **标签补全**
   - 输入 `#` 时弹出标签补全
   - 从已有标签中搜索匹配
   - 支持嵌套标签（`work/project`）

## 验收标准
- 斜杠菜单可触发、可搜索、可插入各类型块
- 块拖拽可重排，保存后顺序一致
- 选中文本出现格式化工具栏，各按钮生效
- `[[` 和 `#` 触发补全菜单，可键盘导航选择
- 插件注册的块/命令出现在斜杠菜单中
- 所有交互支持键盘操作（无障碍基础）
