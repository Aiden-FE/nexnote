Settings are organized by section, with a search box at the top. This chapter lists what each section covers.

## Settings sections

| Section | Contents |
| --- | --- |
| General | Theme, interface language, fonts and sizes, default translation target, startup behavior, help entry |
| Editor | Vault editor behavior: autosave interval, filename bound to title, code theme, Vim mode |
| AI | Provider profiles and feature bindings (chat / writing / translation / embeddings) |
| Git | Use the bundled Git or the system Git |
| Network | Proxy mode and separate proxies for AI / Git |
| Plugins | Install / enable / inspect capabilities |
| Retrieval skills | Enable, reorder, tune |
| Shortcuts | View and rebind every command |
| Updates | Update channel, launch check, auto-download |
| About | Version and links |

Searching settings jumps to the relevant section and also finds items that only appear in a specific section.

## Shortcuts

The shortcut table lists every command and its current binding. Click an entry to rebind it, or disable a command. Common defaults:

| Action | Shortcut |
| --- | --- |
| Command palette | `⌘K` |
| Full-text search | `⌘⇧F` |
| New tab | `⌘T` |
| Source ↔ split | `⌘E` |
| Preview ↔ edit | `⌘⇧E` |

## Resetting settings

If a setting gets misconfigured, you can restore its default in that section; shortcuts can also be restored one by one. Settings persist on this machine and are never written into the vault.
