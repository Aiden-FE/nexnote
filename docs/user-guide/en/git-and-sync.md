NexNote captures every edit as Git history. This chapter explains where commits come from, how to review history, and the principles to follow when a sync conflict shows up.

## Auto-commits and manual commits

Content is first **autosaved** to disk (1.5 seconds after you stop typing by default), then enters the **auto-commit** window: everything edited during that window is bundled into one Git commit, every 30 seconds by default. You can also commit manually at any time from the command palette (⌘K) with your own message.

| Commit type | Trigger | Message |
| --- | --- | --- |
| Auto-commit | Debounce window expires | Generated by the app |
| Manual commit | Command palette | Written by you |

Both intervals are configurable under **Settings → Git**.

## The version timeline

Every page has a version timeline listing the commits that touched it. From there you can:

- see what any given commit changed;
- restore the page to an earlier version.

The timeline reads real Git commits, so it matches exactly what you would see from a command line.

## Sync conflicts

When local and remote both changed and cannot be merged automatically, NexNote **blocks writes** instead of merging for you. This is deliberate: conflicting content is never overwritten behind your back.

A conflict badge appears in the status bar; clicking it opens the sync doctor:

1. It produces a **diagnosis** (conflict kind, affected files, current branch state);
2. it proposes a **repair plan** and shows a preview of the commands involved;
3. destructive operations (such as aborting a rebase) require your confirmation.

Every command in the plan comes from Git itself; the app only diagnoses and orchestrates, and never rewrites history without your confirmation.

## Common situations

| Diagnosis | Meaning | Typical handling |
| --- | --- | --- |
| `conflict` | File contents conflict | Open the sync doctor and follow the guidance |
| `non-fast-forward` | Remote has commits you don't | Pull first, then push |
| `no-remote` | Vault has no remote configured | Configure a remote repository |
| `auth` / `network` | Credential or network problem | Fix credentials or network, then retry |

## Git is more than a sync tool

Even if you never sync to a remote, local Git history still works: the version timeline and restore are available entirely offline. Remote sync is optional, not a prerequisite for using NexNote.
