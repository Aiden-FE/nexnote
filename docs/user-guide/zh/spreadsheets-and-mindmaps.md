除了 Markdown，NexNote 还能在知识库内直接编辑两种二进制格式：`.xlsx` 表格和 `.xmind` 思维导图。它们以独立的编辑器打开，数据仍保存在知识库内并随 Git 版本化。

## 导入或新建

有两种方式得到这两类文档：

| 方式 | 行为 |
| --- | --- |
| 导入 | 从「文件」菜单导入外部 `.xlsx` / `.xmind`，副本进入知识库并打开 |
| 新建空白 | 在页面树「新建」里选「新建空白 XLSX / XMind」 |

导入时内容以原格式保留；新建的是带基础结构的空白文档。

## 表格（.xlsx）

表格在表格编辑器里打开，支持常规单元格编辑、公式与样式。保存写回的是 `.xlsx` 字节，文件路径和扩展名不变。

需要注意：保存整张表时会把当前编辑器内的内容完整写回，请确认编辑的是同一份文件，避免把旧标签页的内容覆盖到新数据上（DEV-104 已修复该链路，但仍建议留意打开了哪个标签页）。

## 思维导图（.xmind）

思维导图由 simple-mind-map 驱动，支持：

- 节点编辑、拖拽整理结构；
- 切换布局结构（向右 / 向左 / 向上 / 向下 / 鱼骨 / X 结构）；
- 主题与标记。

布局结构选择保存在 sidecar 元数据里，不写回 `.xmind` 字节，因此切换结构本身不会让文件产生意外差异。

## 与 Markdown 页面的关系

表格与思维导图是知识库里的独立文件，和 Markdown 页面并列。它们同样出现在页面树、参与自动保存与自动提交；但它们不是文本，双链与全文检索只作用于 Markdown 页面。
