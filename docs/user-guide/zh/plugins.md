插件让你在不改主程序的情况下扩展 NexNote。一个插件可以贡献新的块类型、菜单项、命令和检索策略。

## 插件能做什么

| 能力 | 说明 |
| --- | --- |
| 块类型 | 新增可插入的自定义块 |
| 菜单 | 向编辑器右键菜单、命令面板加入动作 |
| 检索 Skill | 贡献可组合的检索策略，参数由宿主安全执行 |
| UI | 插件 UI 在受限 iframe 内运行，与主程序隔离 |

插件在沙箱内运行，只能通过明确的 API 与主程序交互，不能直接读写你的文件。

## 内置插件

Mermaid 图表与 KaTeX 公式作为内置插件随包提供：它们的清单预置、可禁用但不可卸载，宿主负责块渲染，不启动额外沙箱帧。

## 管理插件

在设置里可以查看已安装插件、启用或禁用，并查看插件声明了哪些能力。第三方插件只能看到经宿主允许的数据，API 协议有稳定版本，破坏性变更会提升主版本号。
