这一章带你走完从零到第一篇页面。全程不需要账号，不需要联网。

## 1. 打开你的知识库

首次启动会进入首启动向导，三选一：

| 方式 | 适用场景 |
| --- | --- |
| 新建知识库 | 从零开始；选择一个父目录并起名，NexNote 会在其中初始化一个普通文件夹 |
| 打开本地文件夹 | 已经有 Markdown 目录；若目录内含 `.obsidian/`，会作为普通知识库打开（双链、别名、标签、Callout、Frontmatter 都兼容） |
| 克隆远程仓库 | 把已有的 Git 远程拉到你机器上 |

一个知识库就是一个普通文件夹，内部必须有 `.git`。NexNote 会创建 `.nexnote/` 存放本地索引、会话与配置——这些是本地运行时产物，不进入版本库；你的 Markdown 与文档元数据才随 Git 版本化。

打开后，左侧是页面树，顶部是命令面板（⌘K），右侧是可折叠的 AI 对话 dock。

## 2. 写出第一篇页面

在页面树点「新建」，可以选三种格式：

- **块编辑文档**：所见即所得，段落、标题、列表、代码块、表格都是独立块。
- **Markdown 文档**：保留 Markdown 原文，可切换源码、分栏与预览三种视图。
- **从 DOCX 导入**：导入即转换为 Markdown 页面，导入后与外部原件脱钩。

在块编辑文档里输入 `/` 会唤起快捷插入菜单，用来插入标题、待办、代码块、Callout、Mermaid 图表与数学公式。

内容会**自动保存**（默认停止输入 1.5 秒后落盘），随后按**自动提交**窗口（默认 30 秒）打包成一次 Git 提交。两处间隔都能在设置里调整。

## 3. 建立第一个双链

在任意位置输入 `[[`，会弹出页面补全。选中目标页面或输入新名字后回车：

| 写法 | 含义 |
| --- | --- |
| `[[页面名]]` | 基础双链 |
| `[[页面名\|显示文本]]` | 带显示文本 |
| `[[页面名#标题]]` | 跳到该页面的某个标题 |
| `![[页面名]]` | 嵌入该页面的内容 |

被引用的页面会在「反向链接」面板列出所有引用位置，同时参与全局图谱与 AI 召回。

## 4. Markdown 文档的三种视图

Markdown 文档可以在三种互斥视图间切换，切换入口在编辑器工具栏：

- **源码视图**：只显示 Markdown 原文。
- **分栏视图**：左侧编辑原文，右侧实时预览，中间分割线可拖动。
- **预览视图**：只显示只读的富渲染结果。

默认快捷键是 `⌘E`（源码 ↔ 分栏）与 `⌘⇧E`（预览 ↔ 最近一次编辑视图），都可以在设置里改绑。

## 5. 让 AI 帮上忙

AI 默认不可用，需要先在 **设置 → AI 供应商** 里配置一个兼容 OpenAI 协议的供应商 Profile（base-url、API key、模型名）。密钥保存在系统钥匙串，不写入知识库。

NexNote 只在**你明确触发** AI 功能时才发起请求——编辑、保存、切换页面、选中文本本身都不会触发。会话有权限模式：对话（只读）、编辑（逐轮审批）、完全权限（自动写回但受护栏约束）。

## 6. 版本历史与同步

底部状态栏显示当前分支与未提交变更。每个页面都有版本时间线，可查看自动提交与手动提交、恢复历史版本。

同步遇到冲突时，NexNote 会**阻塞写入**而不是自动合并，并给出诊断与修复入口；冲突内容不会在你不知情的情况下被覆盖。

## 7. 接下来

- 想了解界面上的每个区域，可以在 **设置 → 帮助 → 新手引导** 里重放应用内引导。
- 遇到问题，先看常见问题；找不到答案时，Git 面板提供「让 Agent 帮助解决」，会在知识库内生成一份诊断文档。
