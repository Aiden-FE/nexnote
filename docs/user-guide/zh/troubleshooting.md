大部分问题不需要重装应用，先按下面几类排查。

## 通用排查顺序

1. 看 Git 面板和同步医生有没有提示；
2. 在设置里搜索相关选项，确认配置没被误改；
3. 重启应用（知识库数据不会丢失）；
4. 仍无法解决时，用 Git 面板的「让 Agent 帮助解决」生成诊断文档。

## 索引问题

全文搜索或反链缺失时，通常是索引还没更新。重新打开知识库或触发一次保存会自动重建增量；如果整页反链丢失，重启应用会触发全量重建。

## 同步问题

同步卡住或提交失败时，点状态栏徽标看诊断。常见原因：

| 症状 | 可能原因 | 下一步 |
| --- | --- | --- |
| 频繁冲突 | 远程与本地同时改 | 用同步医生处理 |
| 推送失败 | 远程有新提交 | 先拉取再推送 |
| 认证失败 | 凭据失效 | 更新 Git 凭据 |
| 网络超时 | 代理或网络不可用 | 检查网络 / Git 代理设置 |

## 二进制编辑器问题

表格或思维导图打开失败时，确认文件没有被其他程序锁定，且不是只读文件。保存失败不要重复强存——先看错误提示，再确认当前 tab 对应的文件路径。

## 插件问题

插件功能不生效时，先在设置里确认它已启用；如果是个别插件出问题，先禁用再启用一次。内置 Mermaid / KaTeX 可以禁用但不可卸载，第三方插件可以整包移除。

## 快捷键不生效

可能是系统级快捷键被占用。到设置 → 快捷键里确认当前绑定，改绑后立即生效，无需重启。
