找东西有两套机制：全文搜索面向「我知道它在某个词上」，AI 召回面向「我知道意思但不确定用词」。

## 全文搜索

按 `⌘⇧F` 打开搜索面板，实时给出命中结果与高亮片段。搜索按命中层级区分展示：

| 层级 | 命中位置 |
| --- | --- |
| 标题 | 页面标题 |
| 标签 | frontmatter 标签 |
| 别名 | frontmatter 别名 |
| 正文 | 页面正文 |

中文支持子串匹配，拉丁字母支持前缀匹配；结果按层级与位置排序。

## AI 召回（渐进式）

当你让 AI 处理一个页面时，它需要先找到「相关的其他页面」。召回分三段，顺序递进：

1. **关键词粗筛**：用全文检索找出候选页面；
2. **关系扩展**：沿双链把候选的邻接页面也纳入；
3. **向量重排**（可选）：如果配置了向量化，再用语义相似度排序。

每一段的结果都标注了来源，回答下方「参考来源」里能看出这条上下文是怎么被找到的。

## 置信度参与排序

召回排序会考虑页面的置信度（默认权重 0.3）：越稳定、被引用越多的页面排得越前。置信度怎么算见下一章。

## 检索 Skill

「检索 Skill」是可组合的检索策略单元，能在设置里启停、排序并调整参数。它只影响 AI 召回，不影响全文搜索。
