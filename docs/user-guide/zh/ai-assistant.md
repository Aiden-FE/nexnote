NexNote 的 AI 能力默认完全关闭：编辑、保存、切换页面都不会触发任何请求。这一章讲清楚怎么配置供应商，以及三种权限模式分别意味着什么。

## 配置供应商

打开 **设置 → AI 供应商**，添加一个兼容 OpenAI 协议的 Profile：

| 字段 | 说明 |
| --- | --- |
| base-url | 兼容 OpenAI 协议的服务地址 |
| API key | 访问密钥，保存在系统钥匙串，不写入知识库 |
| 模型名 | 该供应商下用于对话 / 写作的模型 |

仓库不内置任何云端密钥，也不替你托管。你可以随时在设置里停用或删除 Profile。

## 三种权限模式

每个 AI 会话都运行在一个明确的权限模式下：

| 模式 | AI 能做什么 | 写回方式 |
| --- | --- | --- |
| `conversation` | 只在对话里回答 | 永不改动你的页面 |
| `edit` | 提出修改建议 | 每一轮都要你审批后才写入 |
| `full` | 可以直接改页面 | 自动写回，但受护栏约束 |

建议从 `conversation` 开始，确认效果后再用 `edit`；`full` 适合你已经信任某条工作流之后。

## 什么时候才会发请求

只有**你明确触发** AI 动作时才会发起请求：

- 在对话 dock 里发送消息；
- 选中文字后显式点「翻译 / 写作」；
- 在命令面板里选择 AI 命令。

光标移动、自动保存、切换标签这些动作都不会发请求。

## 翻译与写作

划词工具栏里的「翻译」默认只开一个只读浮层，不写回、不改正文；全文翻译打开临时只读视图，不进入文档树、不写盘。写作辅助在 `edit` 模式下同样逐轮审批。

## 请求失败时

供应商不可达、密钥失效或返回异常时，NexNote 不会卡死或留下半截内容：失败的写入不会落盘，输入仍保留，你可以修正配置后重试。候选模型列表请求失败时会降级为自由输入，不会弹错误或永久清空。
