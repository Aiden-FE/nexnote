双链是 NexNote 的核心：页面不是孤立的文件，而是彼此指向的节点。这一章讲清楚各种链接写法、解析规则，以及怎样浏览这张网。

## 链接解析优先级

在任意可输入位置敲 `[[`，会弹出页面补全。解析一个链接时，NexNote 按下面的顺序匹配：

| 优先级 | 匹配方式 | 例子 |
| --- | --- | --- |
| 1 | 别名（frontmatter 里的 `aliases`） | `[[别名]]` |
| 2 | 页面标题完全相等 | `[[项目周报]]` |
| 3 | 同名多个时弹出歧义选择 | `[[周报]]` 命中多个文件 |

若目标页面不存在，链接会以未创建状态保存（红色），点击即可新建——链接先于页面存在。

## 四种链接写法

| 写法 | 语义 |
| --- | --- |
| `[[页面名]]` | 跳转到该页面 |
| `[[页面名\|显示文本]]` | 显示自定义文字，跳转不变 |
| `[[页面名#标题]]` | 深链到该页的某个标题 |
| `![[页面名]]` | 在当前页内嵌入目标内容 |

嵌入（`![[...]]`）是把另一页的内容渲染进来，被嵌入页本身不被修改。

## 反向链接

每个页面底部的「反向链接」面板列出所有指向它的位置。反向链接是实时从文件内容计算的，不需要你手动维护：移动或重命名页面时，指向它的链接会通过 `renameWithLinks` 一并更新。

## 标签

正文里写 `#标签` 会被收录。标签在侧栏「标签」面板聚合，点击可看到所有命中页。标签与双链互补：双链表达「这页和那页有关」，标签表达「这页属于某一类」。

## 知识图谱

图谱视图把页面画成节点、双链画成连线。它和反向链接读的是同一份关系数据，所以图谱里能看到的连接，反向链接里也一定能找到。图谱只做可视化，不改变任何文件。
