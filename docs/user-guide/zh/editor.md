NexNote 的编辑器以「块」为最小单位。一篇文档由若干块组成——段落、标题、列表、代码块、表格等——每个块都能独立操作。这一章讲清块编辑器的基本用法。

## 块的基本操作

- **新建块**：在编辑器里输入 `/`，唤起快捷插入菜单，从中选择要插入的块类型。
- **调整顺序**：拖动块左侧的手柄可以上下移动块。
- **删除 / 复制**：选中块后右键，或用工具栏里的对应动作。
- **折叠**：标题块和列表块支持折叠，把子树暂时收起。

## 快捷插入（/ 菜单）

在块起始处输入 `/` 就会弹出快捷插入菜单，常用项包括标题、待办、列表、代码块、表格、Callout、Mermaid 图表与数学公式。菜单里的项由内置定义和插件贡献共同组成，装了插件后插件的块也会出现在这里。

## 文档属性

页面顶部的「文档属性」入口可以编辑 frontmatter（标签、别名、创建/更新时间等）。它支持表格和 YAML 两种模式，标准字段与自定义字段都在这里维护。

## 保存与撤销

内容会自动保存到磁盘；「撤销 / 重做」按块工作。编辑工具栏提供常用的格式动作（加粗、斜体、链接、引用等），窗口宽度不够时，多余动作会收进溢出菜单。

## 与源码视图的关系

块编辑文档与 Markdown 文档是两种格式。Markdown 文档始终保留源码，可以在源码 / 分栏 / 预览三种视图间切换（详见「快速上手」的 Markdown 三视图一节）。两种格式都能在同一知识库里混用。
