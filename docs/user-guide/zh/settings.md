设置按分区组织，顶部可以搜索任意设置项。这一章列出每个分区管什么。

## 设置分区

| 分区 | 内容 |
| --- | --- |
| 通用 | 主题、界面语言、字体与字号、翻译默认目标语言、启动行为、帮助入口 |
| 编辑器 | 当前知识库的编辑器行为：自动保存间隔、文件名绑定标题、代码主题、Vim 模式 |
| AI | Provider Profile、各功能（对话 / 写作 / 翻译 / 向量）绑定 |
| Git | 使用内置还是系统 Git |
| 网络 | 代理模式、AI / Git 的独立代理 |
| 插件 | 安装 / 启停 / 能力查看 |
| 检索 Skill | 启停、排序、参数 |
| 快捷键 | 查看与改绑全部命令 |
| 更新 | 更新通道、启动检查、自动下载 |
| 关于 | 版本与链接 |

搜索设置时会跳到对应分区，也能搜到只在特定分区出现的项。

## 快捷键

快捷键表列出全部命令与当前绑定。点击一条可以改绑，也可以禁用某条命令。常用默认快捷键：

| 动作 | 快捷键 |
| --- | --- |
| 命令面板 | `⌘K` |
| 全文搜索 | `⌘⇧F` |
| 新建标签页 | `⌘T` |
| 源码 ↔ 分栏 | `⌘E` |
| 预览 ↔ 编辑 | `⌘⇧E` |

## 重置设置

如果改乱了，可以在对应分区恢复默认值；快捷键也可以逐条恢复。设置会持久化在本机，不写入知识库。
