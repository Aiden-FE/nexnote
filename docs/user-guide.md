# NexNote 用户手册

> 适用版本：v0.1.0（MVP）。本手册基于当前代码事实编写，对应功能均可在运行中的应用内找到。

NexNote 是一款本地优先（local-first）的桌面知识库应用：**块编辑器 × 双链 × Git 版本化 × AI 召回** 一体化的笔记系统。所有数据保存在本地 vault 目录，无需注册账号。

---

## 1. 快速入门

### 1.1 首次启动

首次启动会进入**首启动向导（Onboarding）**：

1. **创建新 vault**：选择父目录并给 vault 起个名字；NexNote 会在该目录下初始化一个普通文件夹（含 `.git`）作为知识库。
2. **打开已有 vault**：选择一个已经由 NexNote 管理过的文件夹。
3. **从远程克隆**：粘贴一个 Git 仓库 URL，先做 preflight（可达性探测 + 一次性授权 token），确认后原子克隆到本地。
4. **打开 Obsidian vault**：选择已有 `.obsidian/` 目录的文件夹；NexNote 会在该目录初始化 Git 并作为普通 vault 打开（方言兼容：[Wikilink](#32-wikilink)、Frontmatter、#tag 等）。

打开 vault 后，编辑器、左侧页面树、顶部命令面板、右侧 AI 对话/召回 Dock 立即可用。

### 1.2 你的第一篇笔记

- 在左侧页面树点 **+ 新建笔记**（或使用 ⌘T 打开新标签再保存）。
- 编辑器为**块编辑器**：每个段落、标题、列表、代码块都是独立块，可以拖拽排序、折叠、添加块锚点 `^id`。
- 输入 `/` 唤起**斜杠菜单**，插入常用块（标题、列表、代码块、Callout、Mermaid、KaTeX 等）。
- 写完一处即可，**自动保存**默认 500ms 防抖后落盘；**Git 自动提交**默认 30s 防抖打包一次（可在设置调整）。

### 1.3 创建第一个双链

在任意块中输入 `[[`，会触发 wikilink 补全；选中目标页面或输入新页面名后回车：

- `[[目标页面]]` — 基础双链
- `[[目标页面|显示文本]]` — 带显示文本
- `[[目标页面#标题]]` — 跳转到指定标题
- `[[目标页面^block-id]]` — 跳转到指定块
- `![[目标页面]]` — 嵌入目标页内容

被引用的页面会在其右侧「反链」面板中看到来源页面和上下文。

## 2. 编辑器核心概念

### 2.1 块（Block）

块是 NexNote 的基本组织单位，与 Obsidian 段落对应，但每个块有稳定 ID：

- **拖拽**：抓取块左侧的拖把手柄，拖到目标位置。
- **折叠**：标题/列表块可折叠子树。
- **块菜单**：右键块手柄弹出块菜单（删除、复制、转为其他类型、插入上下块等）。
- **块锚点**：在块末尾输入 `^my-id` 给块命名，之后可通过 `[[页面^my-id]]` 精确引用。

### 2.2 Markdown 方言（Obsidian 兼容）

- **Wikilink**：`[[target]]`、`[[target|alias]]`、`[[target#heading]]`、`[[target^block-id]]`、`![[embed]]`
- **Frontmatter**：文件头 `---` 围栏，支持 `aliases`、`tags`、`created`、`updated`、`confidence_boost` 等字段
- **Callout**：`> [!note]`、`> [!warning]` 等 Obsidian 风格
- **内联标签**：`#tag`、`#nested/tag`（嵌套用 `/` 分层）
- **代码块**：标准 ` ``` ` 围栏；` ```mermaid ` 会渲染为图表

### 2.3 斜杠菜单（/）

在块起始处输入 `/`，弹出可搜索的块类型菜单：

- 标题 1-6、待办、列表、引用、分隔线
- 代码块、表格、Callout（各种类型）
- Mermaid 图表、KaTeX 数学公式
- 由插件贡献的块（见 [插件开发文档](./plugin-development.md)）

## 3. 双链与图谱

### 3.1 双链解析规则

Wikilink 目标按以下优先级解析（唯一匹配才生效，歧义保留为红链）：

1. **alias**（frontmatter 中的 `aliases` 字段）
2. **title**（页面正文第一个 `# 标题`）
3. **basename**（文件名去 `.md`，不含目录）

路径化的 `[[dir/name]]` 走精确 vault 相对路径匹配，绝不会因 basename 相同而误链到其他目录。

### 3.2 反链面板

在页面右侧或编辑器底部打开**反链面板**，可看到所有引用当前页面的页面，以及引用的上下文片段（前后 ±60 字符）。点击反链可直接跳转。

### 3.3 全局图谱 / 局部图谱

- **全局图谱**：可视化整个 vault 的页面关系。节点大小与入链数正相关。
- **局部图谱**：以当前页为中心的 1 跳 / 2 跳邻居图。
- **过滤**：按标签、目录子树、是否显示孤立页面过滤。

### 3.4 页面重命名

在页面树右键重命名（`fs:renameLinked`）：除了文件改名，还会**自动重写全库所有指向它的 wikilink**，并把别名/锚点保留为可解析目标。索引层会同步刷新反链。

## 4. 搜索与召回

### 4.1 三种搜索方式

| 方式 | 快捷键 | 入口 | 说明 |
| --- | --- | --- | --- |
| 命令面板 | ⌘K / Ctrl+K | 顶部居中按钮 | 跳转命令、最近页面、插件命令 |
| 全文搜索 | ⌘⇧F / Ctrl+Shift+F | 左侧"搜索"页签 | 基于 SQLite FTS5，支持 CJK 子串和拉丁前缀 |
| 页面快跳 | ⌘T / Ctrl+T | 顶部 + 号 | 按标题/别名/路径快跳到页面 |

### 4.2 搜索行为

- **CJK 子串**：「搜索基准」能命中「搜索基准点」「基准」等子串（CJK 双字 bigram 索引）。
- **拉丁前缀**：`nex` 能命中 `nexnote`、`nexora`。
- **分层命中**：标题 > 标签 > 别名 > 正文。
- **FTS 失败兜底**：极端字符导致的 FTS 异常会回退到有界 LIKE 扫描（不会全表扫）。

### 4.3 AI 召回（三阶段）

打开任意 AI 对话（右侧 Dock 的 Chat 页签），输入问题：

1. **FTS 粗筛** — 候选页（默认前 20）
2. **双链 1 跳邻居扩展** — 出/入链页面
3. **向量重排** — 在候选集上做余弦相似度精排（可选关闭）

召回结果会附带来源页路径、块锚点、向量相似度、置信度分数，可点击跳回原文。

### 4.4 召回 Skill

设置 → **召回 Skill** 可启停/排序/参数化多个召回策略（如关闭向量、提高置信度权重），插件也可以贡献新的 Skill（见 [插件开发文档](./plugin-development.md#skill)）。

## 5. 置信度（PageRank）

NexNote 对每个页面计算一个 **0–100 置信度分**，由 6 个因子加权：

| 因子 | 权重 | 说明 |
| --- | --- | --- |
| 内容稳定性 stability | 25% | 最近提交改动越小，分越高 |
| 修订次数 review_count | 15% | log1p 增长，20 次饱和 |
| 作者数量 author_count | 15% | 多作者略微加分（单人保底） |
| 文档年龄 age | 15% | log 增长，1 年饱和 |
| 链接权威 link_authority | 20% | 简化 PageRank（20 迭代）+ 入链数 |
| 手动加权 manual_boost | 10% | frontmatter `confidence_boost` 0–100 |

置信度会影响 AI 召回的排序权重（默认 30%）。

## 6. Git 版本化

### 6.1 自动提交

- 默认开启，防抖 **30 秒**（可在设置调整，最小 500ms）。
- 提交信息自动生成为「保存 a.md / 重命名 b → c」等可读摘要。
- 在冲突标记文件存在时拒绝自动提交（防止把 `<<<<<<< HEAD` 写进历史）。

### 6.2 手动操作

- **手动提交**：⌘S 保存当前文件后立即提交（可选）。
- **时间线**：在文件右键菜单查看「提交历史」，可预览差异并**恢复到任意历史版本**。
- **远程仓库**：在设置 → Git 添加 `origin` 等远程，支持 push/pull；工作区有未提交变更时 pull 会拒绝（除非显式 force）。

### 6.3 冲突与安全

- 检测到 `<<<<<<<` / `=======` / `>>>>>>>` 冲突标记时，自动提交被拒绝。
- 所有写操作都在事务里；断电/崩溃后 SQLite 走 WAL 恢复，不会损坏索引。

## 7. AI 对话与写作

### 7.1 配置 AI

设置 → AI → 添加 Profile：

- **OpenAI 兼容**（任何符合 OpenAI Chat Completions API 的服务）
- **本地 Embedding**（基于 transformers.js 的本地向量化，无需外网）

API Key 只写入系统钥匙串（macOS Keychain / Windows Credential Manager / Linux Secret Service），不会出现在 vault 或设置文件里。

### 7.2 会话即页面

每个 AI 对话是一个普通 markdown 文件（默认保存在 `AI Chats/` 目录），可以被双链引用、被搜索、被召回。点击会话菜单的「转为文档」可把 AI 回答固化为普通笔记。

### 7.3 写作辅助

- 选中文本 → 浮动工具栏 → AI 操作（续写、改写、扩写、总结）。
- 写作时启用召回，AI 会看到相关页面片段作为上下文。

## 9. 设置

设置面板（⌘,）分八个区：

| 区 | 内容 |
| --- | --- |
| 通用 | 主题、语言、字体、字号、启动行为 |
| 编辑器 | 自动保存间隔、模板、文件名绑定标题、Vim 模式、代码主题 |
| Git | 使用系统 Git、自动提交防抖 |
| AI | Profile、密钥、默认模型、特性分配（对话 / 召回 / 写作 / 向量化） |
| 召回 Skill | 启停、排序、参数 |
| 插件 | 安装 / 启停 / 权限管理 |
| 快捷键 | 查看与覆盖默认快捷键 |
| 关于 | 版本、更新通道（stable/beta/alpha）、更新设置 |

## 10. 故障排查

遇到问题先看 [FAQ](./faq.md)；若未覆盖：

- 日志：`~/Library/Logs/NexNote/`（macOS）/ `%APPDATA%/NexNote/logs/`（Windows）/ `~/.config/NexNote/logs/`（Linux）。
- 重置设置：退出 NexNote，删除 `~/Library/Application Support/nexnote/nexnote-settings.json` 等配置文件。
- 重置索引：退出 NexNote，删除 vault 根目录下的 `.nexnote/index.db`（下次启动自动重建）。
