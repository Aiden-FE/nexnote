# 统一编辑器工具栏与光标处快捷插入

编辑器顶部不再单独显示页面文件名：文件名只作为 Tab 标识显示，编辑相关操作统一进入编辑器工具栏。工具栏保持单行并采用 Icon-first：动作以图标按钮为主，通过 hover 与 keyboard focus 可达的统一 Tooltip 展示名称、快捷键或禁用原因，每个按钮提供准确的 `aria-label`。AI 入口是明确例外，使用 Sparkles icon + `AI` + chevron；仅靠通用 Sparkles 无法稳定表达 AI 语义。常驻高频动作固定为撤销、重做、标题/段落、粗体、斜体、双链和 AI，另保留适用的视图或导航入口；删除线、行内代码和外链收入“格式”动作组，结构与媒体收入“插入”动作组。同类低频动作以带图标和名称的下拉呈现，超出空间时完整动作组再收进响应式“更多”，不得把固定分类与空间溢出混为同一概念。Tab 只负责页面识别与切换，不承载编辑器操作。

划词工具栏只在存在非折叠选区时出现，采用相同的 Icon-first 和 Tooltip 规则，所有 AI 操作折叠为一个 AI 下拉入口；菜单保留适用动作与快捷键提示，生成中提供独立的取消入口。块菜单、右键菜单和 `/` 菜单属于文字化命令菜单，不强制改为纯图标。

没有选区时，用户仍可通过编辑器工具栏或 `/` 快捷输入入口触发当前光标处动作。两种编辑模式共享快捷输入动作定义、名称、图标、能力判断和执行语义，但可按模式隐藏无法可靠表示的动作；顶部下拉按稳定信息架构排序，`/` 菜单按上下文相关度和搜索结果排序。`/` 可在当前可编辑行的行首或空白之后触发，包括标题、列表项和引用，但代码块、行内代码、URL、路径、数学表达式或单词中的 `/` 不触发。

`/` 菜单支持中文名称、英文别名及常见 Markdown 记号过滤，例如 `/h2`、`/heading 2` 与 `/二级标题` 指向同一动作；上下方向键移动，Enter 或 Tab 确认，Escape 关闭。动作确认后消费触发用的 `/` 与过滤文本；Escape 关闭菜单但保留原文；删除越过触发位置时关闭；无匹配项时展示明确空态而不执行动作。菜单默认按“基础块、插入、AI、插件”分组，过滤后按匹配度重排；最近使用只能辅助组内排序，不能越过分组或上下文能力边界。

快捷输入动作区分三类语义：

- 正文、H1–H6、列表、任务列表、引用和代码块是块类型转换，只在触发词前没有有效正文时显示；行首确认后消费触发词并转换当前空行。已有正文的行内不展示这些动作，用户应使用顶部“标题/段落”等类型转换工具。
- 分隔线、表格、图片、附件、图表和正文目录是独立内容插入；已有正文时只能在安全块边界插入，不得从光标处截断当前文本。
- 双链和 AI 插入等行内动作可在当前光标执行。AI 快捷插入使用当前光标及当前段落附近上下文，结果在光标处流式插入，不替换已有正文。

快捷插入和 Chat Dock 的回复插入都遵循当前编辑上下文：块编辑模式写入当前 TipTap 光标，Markdown 源码视图或分栏视图写入当前 CodeMirror 光标；没有活动编辑器时禁用插入，不写入其他页面。预览视图不提供快捷输入。

修订（2026-09，临时翻译）：划词工具栏的 AI 下拉新增划词翻译，结果在选区旁只读浮层展示、可复制，随选区消失；编辑器工具栏新增全文翻译，打开临时只读翻译视图——内存态、不写盘、不进文档树、关闭即弃。目标语言每次可选并记住上次选择；翻译请求固定关闭 reasoning。本轮不提供任何译文写回路径，未来若需替换原文另立决策。翻译与权限模式（ADR-0009）无关，因为它没有写回能力。

## Consequences

- AI 不再因为多个按钮挤占划词工具栏或编辑器工具栏的空间；AI 入口和所有动作组的子动作必须可键盘访问。
- `/` 菜单既可承载非 AI 快捷动作，也可承载需要额外指令输入的 AI 插入动作；块编辑和 Markdown 编辑必须分别实现真实输入链路，不能只测试人工调用编辑器 hook。
- 两种编辑模式需要各自实现“当前光标插入”，但对用户保持一致语义；Chat Dock 不能只依赖块编辑器的活动实例。
- 标题工具是当前块或当前行的类型转换：完整支持正文与 H1–H6。菜单将 H1 标为“页面标题 H1”并说明首个正文 H1 与文件名同步；跨复杂结构的多块转换应禁用并解释原因。新建空标题属于快捷输入，不与类型转换混为一谈。
- 文件名、工具栏、Toolbar Action Group、响应式溢出入口、Tab、划词工具栏和对话 dock 是不同的界面概念，不得以同一折叠状态或同一职责实现。
- Tooltip 必须同时服务 pointer hover 与 keyboard focus，支持 Escape 关闭；禁用按钮仍可展示不可用原因。原生 `title` 不能作为完整 Tooltip 交互的替代。桌面首期不单独设计触屏长按提示，但所有下拉菜单项必须保留“图标 + 文案”。
- 验收分四层：共享动作模型单测覆盖分组、别名搜索、模式能力与上下文过滤；编辑器集成测试必须走真实键盘输入而非直接调用 `handleTextInput`；Renderer 测试分别挂载真实 TipTap 与 CodeMirror，覆盖出现、过滤、键盘选择、Escape、触发文本消费和插入结果；打包 smoke 在块文档与 Markdown 文档各执行一次真实 `/` 操作，使用实际稳定 selector 验证菜单可见且动作生效。
