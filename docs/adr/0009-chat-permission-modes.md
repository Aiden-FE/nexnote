# Chat Dock 会话权限模式：对话 / 编辑 / 完全权限

参考 Cursor，Chat Dock 的 Agent 工具按会话权限模式分级授权。**对话模式**：工具只读，不产生任何文档写操作。**编辑模式**：AI 可产生编辑提案，按轮次成批审批——每轮回答的所有提案合成一个 diff 批次，可整批 Accept/Reject 或逐项取舍，每次 Accept 以单个 undo 单元写回。**完全权限模式**：工具自动执行、不逐次询问，但保留五条硬护栏——作用域限于当前会话上下文涉及的文档；禁止 shell、页面删除/重命名、vault 配置等非文档编辑操作；每次自动写回仍是单个可撤销的 undo 单元；对话流保留完整工具审计（名称/目标/结果摘要）；不豁免 ADR-0005 的显式意图与零隐式请求门禁。

模式为会话级状态、随会话持久化，新会话默认对话模式；切换只影响之后的操作，不追溯授权已被拒绝的提案。三模式仅约束 Chat Dock 的 Agent 工具：编辑器侧的划词 AI 写作（diff + Accept/Reject）、临时翻译、快捷插入维持各自已定案语义，不叠加模式判断。

## Consequences

- 编辑审批复用 AI 写作的写回语义（单事务、单 undo 单元），不另建第二套 diff 管线。
- 完全权限模式是「自动但不越界、可撤销、可审计」，不是无限制的系统权限。
- 模式切换控件需键盘可达；权限升级不留后门授权历史。
