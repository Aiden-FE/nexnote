# NexNote 快捷键速查表

> 适用版本：v0.0.1。Modifier 约定：`Mod` = macOS 上的 `Cmd` ⌘，Windows/Linux 上的 `Ctrl`。
> 所有全局快捷键可在「设置 → 快捷键」中自定义或禁用。

---

## 全局导航

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 命令面板（Command Palette） | `Mod + K` | 打开全局命令面板，搜索命令/页面/插件 |
| 搜索（Find in Files） | `Mod + Shift + F` | 打开全文搜索面板 |
| 打开设置 | `Mod + ,` | 打开应用设置 |
| 保存 | `Mod + S` | 立即保存当前文件并触发自动提交 |
| 新建标签页 | `Mod + T` | 打开新的空标签页 |

---

## 编辑器（编辑态内）

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 斜杠菜单 | `/`（块起始处） | 插入块类型菜单 |
| 新建块 | `Enter` | 在当前块后创建新段落 |
| 删除块 | `Backspace`（空块） | 空块按 Backspace 删除并合并上一块 |
| 撤销 / 重做 | `Mod + Z` / `Mod + Shift + Z` | 编辑器历史栈 |
| 块拖拽 | 抓取块左侧手柄 | 拖到目标位置 |
| 块菜单 | 右键块手柄 | 删除、复制、转换类型、插入上下块 |

### 编辑器内选区格式

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 粗体 | `Mod + B` | 加粗选中文本 |
| 斜体 | `Mod + I` | 斜体选中文本 |
| 删除线 | `Mod + Shift + X` | 删除线 |
| 行内代码 | `Mod + E` | 包裹为行内代码 |
| 链接 | `Mod + K` | 插入链接（选中时改写为链接） |

## Wikilink

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 插入 Wikilink | `[[` | 触发页面补全面板 |
| 带别名 | `[[目标\|显示文本]]` | 链接文本自定义 |
| 跳转块锚点 | `[[目标^block-id]]` | 精确跳转到命名块 |

---

## 搜索面板

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 聚焦搜索框 | `Mod + Shift + F` | 打开并聚焦搜索输入 |
| 跳转到结果 | `Enter` | 打开第一条匹配结果 |
| 关闭面板 | `Esc` | 关闭搜索面板（也可点击其他结果项跳转） |

---

## 命令面板（`Mod + K`）

| 功能 | 说明 |
| --- | --- |
| 输入关键词 | 按标题/别名/路径模糊匹配页面，并匹配应用命令与插件命令 |
| `↑` / `↓` | 移动高亮 |
| `Enter` | 执行所选命令 / 跳转到所选页面 |
| `Esc` | 关闭命令面板 |

命令面板是扁平结果列表：每个结果带一个类别标签（**页面**、**应用**、**视图**、**知识库**、**搜索**、**标签页**、**AI**、**主题**、**插件**），不做分组折叠。

## AI 对话 Dock

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 发送消息 | `Mod + Enter` | 在输入框里按 Cmd+Enter 发送 |
| 换行 | `Enter` | 输入框 Enter 为换行（与发送区分） |

## 自定义

所有全局快捷键支持在「设置 → 快捷键」中：

- 修改触发键（同一命令支持覆盖默认）
- 禁用（设置 `disabled: true`）
- 冲突检测：绑定到同一键的命令会在 UI 中标红提示
- 重置：一键恢复默认

---

## 附：修饰符规范

```
Mod   = Cmd（macOS） / Ctrl（Windows/Linux）
Ctrl  = macOS 上的 Control（不替换为 Cmd）
Alt   = Option ⌥（macOS） / Alt（Win/Linux）
Shift = Shift ⇧
```

绑定顺序：`Mod + Ctrl + Alt + Shift + Key`。Key 部分首字母大写（如 `K`、`Enter`、`Space`、`Esc`、`F1`–`F12`、`Up`/`Down`/`Left`/`Right`）。
